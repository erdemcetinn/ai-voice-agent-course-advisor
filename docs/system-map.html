One question, step by step

From a real session with synthetic student s001 (Maya). The model was called three times; the tools took 3 ms in total.

  1. You → loop
    Can I take ITC 6680 next semester?
  2. Haiku · call 1
    A tool request instead of an answer: get_transcript
  3. Loop runs · get_transcript("s001")
    ITC 6105 (A), ITC 6610 (A-) · 6 / 34 credits · GPA 3.83 · 2 ms
  4. Haiku · call 2
    Tool request: search_catalog("ITC 6680")
  5. Loop runs · code found, exact lookup
    CISSP Preparation · prerequisites: ITC 6610 ; ITC 6620 · restricted elective · 1 ms
  6. Haiku · call 3
    You cannot take ITC 6680 next semester. You have completed ITC 6610, but you have not yet taken ITC 6620.

Right now Haiku checks the prerequisites itself. On an earlier run it answered the same question with a self-contradicting reply. Phase 4 measures how often that happens; phase 5 hands the check to a deterministic planner.
